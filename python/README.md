# Python – Nassau Candy Distributor Analysis

## Project Overview
This folder contains the Python-based analysis of the Nassau Candy Distributor dataset.

The objective is to analyze sales performance, factory operations, products, geographical distribution, and factory-to-customer route combinations using Python.

## Tools & Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Key Activities
- Data loading and inspection
- Data cleaning and preprocessing
- Missing-value and duplicate analysis
- Data modelling and table merging
- Exploratory Data Analysis (EDA)
- Sales and profitability analysis
- Factory and product performance analysis
- Geographical and route analysis
- Data visualization
- Interactive dashboard development using Streamlit

## Project Files
The Python folder contains Jupyter notebooks, Python scripts, and related analytical resources.

## Key Business Questions
1. Which factories generate the highest sales?
2. Which products contribute most to total sales?
3. Which geographical regions generate the highest revenue?
4. Which factory-to-customer route combinations have the highest sales?
5. How does shipping-mode usage vary?
6. What business insights can help improve operational decisions?

## Important Note
This analysis uses the available dataset. Route combinations represent factory and destination combinations, not verified physical road routes. Actual delivery distances and transportation costs are not available in the source data.
